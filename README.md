## 下单前后，怎么验证你买到的真是 GIA

方法只有一条：晚高峰 traceroute。CN2 GIA 的定义是从你的服务器到大陆用户全程走 AS4809 骨干，中途不落回 163 网。开通后在服务器上执行：


traceroute -n 202.96.209.5


看输出里的两段地址就够了：**59.43.x.x 是电信 CN2 骨干，202.97.x.x 是 163 网**。全程 59.43、没出现 202.97，才是真 GIA；只要冒出 202.97，那就是 CN2 GT 或者普通 BGP。测试时间选北京时间 20:00 到 22:00——这是低等级线路最堵的时段，白天测出来的结果参考价值有限。

这套方法不挑商家。宣传页写着 CN2 GIA、实际给 CN2 GT 甚至普通 BGP 的情况并不少见，任何一家到手先跑一遍，几秒钟见分晓。

## 常见问题

**CN2 GIA 和 CN2 GT 差在哪？**
差在回程是否全程走 AS4809。GIA 从服务器到大陆全程电信 CN2 骨干；GT 会在中途落回 163 网，晚高峰表现差一截。用上面的 traceroute 一测便知，出现 202.97.x.x 就不是 GIA。

**香港 VPS 到大陆延迟多少算正常？**
电信家宽到香港正常在 30–50ms，晚高峰也不该明显劣化，超过太多就要怀疑线路被换了。作为参照，洛杉矶机器到大陆普遍 150ms 起步。

**为什么 BandwagonHost 香港套餐比别家贵这么多？**
贵在 GIA 转发成本（部分市场约 $120/Mbps）、三网直连的线路配置，以及香港线本来就是它全目录里最贵的产品线。对延迟不敏感的话，它家洛杉矶 CN2 GIA-E 季付 $49.99 更划算。

**CN2 GIA 机器能放容易被攻击的业务吗？**
不能。GIA 容量有限也不带清洗，被 DDoS 后 IP 会直接 nullroute，攻击停了才恢复。高暴露风险的服务换带防御的线路。
